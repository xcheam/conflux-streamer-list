# kmorets整理频道库

适用于[汇流直播](https://conflux.kami.asia/streamer-list-format)的主播单，采用 `schemaVersion: 1` 格式。

想及时获取名单更新、推荐直播间和后续整理内容，欢迎加入我的 Telegram 频道：[t.me/kmorets](https://t.me/kmorets)。频道会分享直播发现、主播单更新、平台使用技巧和精选内容，适合喜欢看直播、寻找新主播，或想把多个平台直播间集中管理的朋友。

如果你发现某个主播已经改名、换房间号、停止直播，或发现了值得加入的直播间，也欢迎在频道留言反馈。你的反馈会帮助这份主播单持续更新。

## 下载与导入

下载仓库中的[合并筛选主播单.json](./合并筛选主播单.json)，在汇流直播中选择导入文件。

也可以打开 JSON 文件，点击 GitHub 的 **Raw** 按钮，复制原始文件的 HTTPS 地址，在汇流直播中订阅该网址。订阅链接需要直接返回 JSON 文件。

推荐先加入 Telegram 频道，再订阅 JSON 地址：这样可以看到版本更新说明和名单变更提示。频道地址：[https://t.me/kmorets](https://t.me/kmorets)。

## 为什么整理这份名单

不同平台的直播入口分散，分类名称和房间号格式也不一致。这个项目把多个平台的公开直播资料整理成汇流直播可以直接导入的文件，让你可以在一个列表里按内容找到王者荣耀、颜值与才艺、舞蹈、音乐、聊天户外、助眠 ASMR 和 PK 直播间。

这份名单适合用来发现新主播、建立自己的观看清单，也适合在手机上集中管理多个平台的常看直播。它不是任何平台的官方推荐榜，也不代表主播与本项目存在合作关系。

## 整理规则

合并五份主播单，按“平台 + 房间号”去重，并合并重复记录的分区、补充缺失信息。不同平台的同名主播不会仅凭昵称合并。

根据主播名称、直播标题和已有简介文字，筛除带货、教学、培训、老师、健身、创业等特征的账号。主播名字明确标注年龄超过 35 岁时筛除；没有明确年龄的信息不作推测。

名单包含公开资料标注为女性的主播，以及未公开可解释性别资料的主播，不保证全为女性。筛选主要依据公开文字，没有逐间观看直播或核验账号历史，可能有遗漏或误判。

## 数据说明

这是一份合并整理的名单，不是完整的实时热度榜，也没有每平台或每分类 100 名的数量限制。部分条目来自历史名单，收录不代表当前正在直播。名单会随着公开资料变化而更新，更新说明会同步发布在 [Telegram 频道](https://t.me/kmorets)。

主播可能改名、停播或更换分类。头像由各平台服务器提供，可能失效或受到访问限制。niconico 的节目号通常在每次开播时变化，旧节目结束后需要更新。

所有房间号均使用字符串保存。未取得的头像以空字符串保存，应用可使用占位图显示。

## 更新维护

替换 JSON 文件时保留 `schemaVersion`、必填顶层字段以及条目中的 `platform`、`roomId`、`name`，同步更新 `updatedAt` 和本 README 的统计数据。

格式要求以[官方主播单格式说明](https://conflux.kami.asia/streamer-list-format)为准。
